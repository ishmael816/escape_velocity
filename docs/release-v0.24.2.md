# v0.24.2 / C5：让自动玩家把成长转化为收入

基线 C4：`dda84103ae6d043eab3bc7e44f3c8cf171b6051f`。仅改两处自动玩家决策，以及应用版本标识；卡牌、结算、支持、夜间、搜索、供给、七次行动、N−1终局均未修改。真人仍可自行选择成长或收入。

## 确认的问题与修正

1. 旧启发式对无关成长给21分，普通收入通常19–21分；每路线只有两种技能，旧的“少于三项技能”分支总会给21。因此已有AABBC、现金4、可见A-M能买能安排的局面，仍会先买无关成长。新判断只在已经归档至少两项技能、原首选为无关成长时触发：从原候选中优先选择技能满足、扣除原价后能按现有合法日程安排的收入牌。缺本金、无时段、已知团建暂停等情况不触发。能解锁已有手牌的必要成长、初期成长、支持和搜索原优先级保留。
2. 旧AI把“高级牌暂时安排不了”直接当成腾位理由，可能为需要6本金的A-X撤掉当前收入，撤后现金仍只有2。新判断要求当前现金加本次撤牌实际返还的本金足以支付目标本金，才会这样退役收入牌。没有发钱、提前结算或读取暗牌；可返还4本金加现金2升级A-X的路径仍可用。多张本金联合释放的最优规划不在本补丁内。

代码变化位于引擎自动玩家区。用基线快照对比确认核心规则区和卡牌生成数据完全一致。183项测试全部通过，含新增11项AI回归；87个JS/MJS语法检查和静态构建通过。测试中的DOM模拟不是浏览器实玩。
