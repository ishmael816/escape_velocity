# A4 实体打印包的生成与维护

成品在 `output/pdf/`，优先阅读其中 `打印说明.md`。三人整包 27 页；也可分别打印公共模块一次、卡组与玩家组件各 N 次。

## 生成

```powershell
node scripts/export-print-data.mjs
python scripts/build-print-kit.py
python scripts/check-print-kit.py
```

生成依赖 ReportLab、pypdf 和 Windows 微软雅黑字体。校验脚本依赖 Pillow、pypdfium2，并优先使用系统 PATH 的 Poppler `pdftoppm` 渲染。

`export-print-data.mjs` 从当前卡牌与视觉模块导出 JSON 数据。生成器读取此数据，不手工复制卡牌费用、收益、技能门槛或事件时段。特殊能力的简短描述及帮助规则在生成器中维护；游戏规则变更时应同步核查。

`print-manifest.json` 列出每张实体牌的编号、页码、位置、尺寸和成品页数。中间数据及校验图在 `tmp/pdfs/`，不作为玩家交付内容。

## 实体转换约定

- 活动与机会牌宽 36 mm；1/2/4h 分别高 22/44/88 mm。
- 每位玩家使用两张横向 A4，白天和夜晚七列对齐；槽内上、左边深色模拟内凹槽。
- 工位直接印在板上。摸鱼覆盖片在原工位上提供 1h 活动位与 1h 机会绑定位；仍然只解锁 1h 活动时间。
- 夜晚用独立 2h 机会绑定位，与上方 2h 活动位一一对应。
- 资源用可擦写账本，永久能力、技能归档及对应签放板旁。
- 不同高度的成长与高级牌不能直接洗成不可辨认的牌堆，因此用统一 30 ×22 mm 抽选签代抽。每个副本各有一枚签，签和实体牌共同移出/返回可用池，保持数量守恒。
- 活动费用显示负数；箭头后的资源是获得值。公文包表示计入副业收入。底栏的购/学是取得费用，理智下限只检查不扣除。
- 核心能力不是支付技能牌：技能只提供永久资格。

PDF 的普通正文与数值仍需结合当前引擎人工审阅，不能只靠文本完整性检查。此次已渲染全部 13 张独立模块页面；三人包仅由这些页面按份数组合。
