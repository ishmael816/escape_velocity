# 卡牌工坊

`npm run dev` 后打开 `/card-studio.html`，或从游戏顶部的「卡牌工坊」进入。当前载入 v0.32 的全部55种活动牌、7种事件牌，直接使用 demo 的卡面绘制。

## 修改卡牌

1. 按流派、4h / 8h、价格、持久度或关键词筛选，点击卡面。
2. 在右侧按「购买／打出／结算」修改；卡面实时更新。特殊效果可展开灵感、过牌、骰子、成熟、联动等分组。下一张／上一张可逐张审阅。
3. 改动自动保存到当前浏览器草稿，可对比原版、撤销／重做、还原单张，也可复制或新建卡牌。活动牌保持每种四份。
4. 点击「应用到本地 demo」，确认改动清单后写入源卡池。刷新游戏并新开一局，使用修改后的数据。现有对局不适合中途换规则。

## 文件与备份

- 唯一源数据：`data/cardpool-v31.json`。
- 应用时同步生成 `src/cardpool-data.js` 和 `docs/cards-v0.32.md`。
- 原卡池自动备份在 `data/cardpool-backups/`，不会提交到 Git。可导入备份，再应用以恢复。
- 「导出卡池」下载完整 JSON；「导入」替换草稿，不会立即覆盖正式数据。
- 静态部署没有文件写入接口，仍支持筛选、编辑、浏览器草稿与 JSON 导入导出。可把 JSON 带回本地工坊应用。
- 本地接口只接受本机同源请求；版本冲突时拒绝覆盖。先导出自己的草稿，再重新载入源卡池。

工坊支持现有引擎的效果组合，不会把任意描述文字自动编译成新规则。不兼容的组合会显示校验提示并阻止应用。完整 JSON 可检查所有字段；数值合理性仍需对局测试。

v0.32 的指示物、相邻目标、交易与交叉消耗由完整卡牌 JSON 的 `mechanic` 对象控制；对应卡面文字和牌表会自动生成。修改 `effect` 说明不能改变这些规则。基本价格、技能、理智、费用、收入与进度仍使用表单。主数据文件保留旧路径，版本字段必须保持32；一次性迁移脚本不得在编辑后重跑。
