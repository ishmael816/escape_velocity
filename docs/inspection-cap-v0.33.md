# 查岗追查上限与理智保留

每张事件的查岗轮数不变。每轮先掷一次 D6，命中该玩家未受保护的摸鱼活动后，最多追加一次追查；追加检查即使命中，也不再继续。本周已命中的日期再次掷出时结束该玩家本轮检查，不重掷、不重复处罚。多人共用骰子，但分别退出追查。

查停的活动本周不获得收入、不支付执行费用、不推进进度、不产生执行效果，每张仍罚 1 资金。II 级活动只计一张。牌仍在日程中，保留打出时的正负理智影响和已有进度；撤回时撤销对应的日程影响。支持牌被查停时不预扣维持费，仍保留正理智影响，不因这次查岗直接触发低理智事件或失去其他卡牌的理智门槛。

此次只修改查岗。团建、就医，以及未被查停的活动付不起费用时的原有处理不变；事件本身的低理智检查仍存在。

设计结果：查停付费支持牌会省下当周执行费用，同时支付查岗罚款。这是“暂停结算、保留打出效果”的直接结果，后续试玩需要观察是否使工作日放置高维持费支持牌过于划算。

兼容：未结算的旧存档会使用新查岗规则，事件提示按当前规则显示；已经结算的历史周不重算。

验证覆盖：追查最多一次、多轮独立启动、本周重复日期、多人分别退出、履职保护、支持理智与费用、低理智事件门槛、正负理智保留、成长进度及撤回后的理智。
