# v0.23 体验迭代记录

基线：v0.22 / `87d8f798b0d7733fded4098659e15660ddd7178a`。独立云端两局发现市场购买阻止刷新、成长缺件、搬移消耗大量行动、保护默认回周一；成长局第5周8张，基础局第9周10张且中途转成长。样本不能证明整体平衡。

## 测量与候选验收（在改规则前确定）

1. 保留128项仍适用回归；规则变化逐项迁移。错误操作全状态不变、结算和读档幂等不放宽。
2. 自动对抗覆盖2/3/4人、至少8个种子、全部座次、基础/W/A/B/C/混合/重复牌策略。相同策略与种子比较基线与候选。单一机器人不作为结论。
3. 市场持续滞销龄应有硬上限（目标不超过3周），不能被另一时长区的一次购买无限阻止。成长缺件应有合法、有限供给的主动补救，并保留原有购买及安排成本。
4. 纯搬移的付费行动平均数至少减半；不增加每周手算费用。旧日程不得被回写，免费重排不得刷钱、技能、收入或跳过回合。
5. 自动局至少95%在24周内结束；各成长路线能实际获胜，成长逃离构筑平均应比基础重复牌至少少1张，不出现有证据支持的单一路线支配。2人对抗首胜份额超过70%时必须调查，而非直接宣告平衡。
6. 连续无有效动作周的90分位目标不超过2周，且较基线改善。解释资金等待、最后一人被N−1终局截断和机器人局限，不把所有未逃离者当系统死锁。
7. 记录首次预测达标、实际结算达标、逃离周、在场牌数、维护费、有效动作、免费/付费重排、市场龄、逐策略胜负及失败盘面。静态组合、自动对抗、真人浏览器分别报告。

候选优先限制在市场流动、成长补救、重排和保护选择。没有必要加入退出排名；维持当前终局范围。具体设计在基线结果后选择，未达标要记录失败并继续迭代，不把固定局数跑完当作完成。

## C1 实施与校准

本轮选择三个引擎改变：展示牌逐张两周过期；缺失成长从有限公共供给按原价购买；未来日程移动／撤回免费、首次安排仍付费。另修正保护候选和导出版本标签。32张卡的数字与门槛未改，没有追加递减、排名或新的结算步骤。

自动策略先后暴露了四种测试器盲区：拒绝有用重复牌、不会移除多余夜间压力、只接受单次撤回立即达标、刚撤回就重新安排同一牌。最终策略修订5使用外部策略记忆，允许逐步淘汰弱牌；每次均用同一策略对基线与候选重跑，不把策略改善算成规则收益。早期汇总以policy-v1至v4-summary留档，不混入最终对照。

## 最终本地对照（候选，不是最终平衡认证）

相同8个种子、2–4人、全部座次、7种策略，各504个配置（497个不同整桌配置），详细数据在 [对照报告](experience-comparison-v0.23.md)。

- 24周内结束：旧494/504，新494/504；30周内结束：旧494/504，新495/504。**结束率基本持平，不能声称大幅改善。** 候选未结束配置都含永不成长的repeat策略，完整失败盘面保留。
- 展示计龄最大值9→2周。供给耗尽时同一UID可重现，连续可见最大值仍7周，不能声称所有展示牌两周一定变成不同牌。
- 付费重排归零，购买与首次安排成本不变。三张合法搬移、8h占位、过去时段禁改、资金守恒与读档已专测。
- 实际逃离者的平均周数：W 7.98→6.12，A 8.73→6.68，B 10.02→7.25，C 9.49→7.81，mixed 6.34→5.80；basic优先12.18→9.38，repeat 14.08→11.64。均值有末位截断与幸存者条件，不能当作真人因果实验。
- 成长策略平均在场4.82–5.76张，repeat为8.67张。基本流程的成长效率与牌数收益可观察。
- 所有成长策略连续无有效动作周P90≤2；basic为3、repeat为5，仍未达到“所有策略≤2”的理想目标。
- **mixed两人首胜份额81.25%，仍触发>70%的调查线**（基线84.38%）。具体对手的小样本配对不能证明绝对支配或完全平衡；独立云端混合对纯色为下一轮必要验收。没有用这一轮数字宣告平衡结束。
