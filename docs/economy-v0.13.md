# v0.13 · 躺平与固定工资

> 历史版本：包含未经用户认可的开局赠牌设计，v0.14 已移除。本文开局配置及相关测试不能代表当前规则，见 [空手开局重测](empty-start-v0.14.md)。

躺平消耗当日一次行动，只跳过，不增加资金、理智或灵感，也不刷新市场。已经安排的活动继续保留并按正常规则结算。界面移除“整备资金”参数，每周基础工资默认从 2 调为 3；已逃离玩家仍不领工资。

不考虑活动、事件及罚款时：旧版一周跳过七次可以获得 7＋2＝9 钱，新版固定获得 3 钱。积极购买、安排的玩家同样领取 3 钱，资金补给不再与闲置行动数量挂钩。工资与奖金仍不计入逃离收入轨道。

v0.13 使用独立存档，保留旧存档；需要新开一局测试。

验证：76 项引擎测试、静态构建、卡池静态检查与骰子概率检查通过。覆盖跳过不增加资源、行动轮转、整周跳过后仅增加 3 钱，以及工资变更后的支持牌维持费、查岗罚款、活动收益和找牌付款时序。

使用相同的 2/3/4 人、三个随机种子与 A02 起始牌运行九场自动对局。三场两人局分别在第 18、22、16 周结束；六场多人局触发 35 周测试保护上限，市场最长连续 14–26 周未变化。这个上限不是游戏终局规则，模拟脚本因此返回失败状态。自动玩家只能检查规则运行，不能证明真人体验或平衡。

六场未结束的多人局中，旧版末次结算玩家资金范围为 87–456，新版为 5–226，资金堆积有所减少，但没有消失。资金变化会改变自动玩家的购买和安排，不能把这当成相同日程下的精确经济对照。多人停滞还需单独检验，不能归因于工资一个参数。
