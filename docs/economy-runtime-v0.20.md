# v0.20 接入与测试报告

本轮落实商业自选本金、雇人归档、版图灵感、开发并行、重复过牌。完整规则见 [当前设计](cardpool-design-v0.10.md)，卡值见 [牌表](cards-v0.10.md)。

## 数值选择

普通牌保留 2h：买 2/收入 1/压力 1，4h：买 3/收入 2/压力 1，8h：买 5/收入 3/压力 1 的比较模板。

稳定供货 C09：买价 4、8h、CCC，每 4 本金收入 1。自有品牌 C10：买价 6、8h、CCCC，每 3 本金收入 1。两者均提供支持 1；本金返还，不收本金维持费，调整花行动。

本金 12 时三种比例每周分别产出 6/4/3。统一工资、支持费、储备和复投条件，连续第六周为 50/19/10；这说明 2→1 的增长明显更快，不能仅靠“晚拿到牌”约束。该对照忽略买牌、成长与查岗，不是对局收入预测。详见 [模型与计算边界](model-v0.20.md)。

并行用购牌溢价和高级技能支付；灵感用留白空间支付；雇人用原价加 2 和日程支付；重复找牌用时间、门槛或费用支付。取消旧翻倍效果，保留基础“下一张收入 +1”。没有新增收入上限、开局赠牌或固定结束周。

## 验证

- 123 项规则测试：包括自选本金合法性、扣款与返还、无收入上限、灵感放置/清除、并行容量、8h 跨格、夜晚惩罚、保护目标、雇人、找牌暂停/续存档等。
- 卡池结构、骰子概率、静态构建检查通过。
- 四套预置中后期日程 AB/AC/BC/WC，均经实际安排接口构建，连续三周平静结算通过；各枚举 0–3 次查岗，共 1,036 个序列。已供应归档与资金，因此不能据此断言取得速度或路线胜率。
- 九局自动对局：2/3/4 人，每组种子 7、42、20261009，均结束于 10–16 周。数据见 [模拟记录](simulation-economy-v0.20.json)。测试保护上限 35 周不属于游戏规则。机器人已调整退役旧牌和本金储备决策，没有为加速机器人而改人类规则。
- 浏览器检查了本金输入、安排扣款、行动计数、版图指示物与并行卡面，无 JavaScript 异常；8h 叠放保留底牌标题及主要效果，提供上下半天的安排入口。

## 待真人确认

1. 商业取得 CCC/CCCC 与积累本金的实际速度，3→1 是否会在真实市场中过快。
2. 创作共用灵感门槛是否让 AB 过于划算；并行的高买价是否足以抵消省槽收益。
3. 雇人是否有足够机会买到缺失颜色，重复找牌能否缓解卡市场，而不延长实体结算太多。

自动模拟验证规则可运转，不能证明平衡或 60–90 分钟时长。旧 A4 图纸未更新；本地 v0.20 需新开局。
