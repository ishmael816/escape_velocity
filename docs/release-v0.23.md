# v0.23 候选 C1：减少等待与搬牌

状态：可交付独立实玩的候选，不是“已证明绝对平衡”。基线为 v0.22 / `87d8f798b0d7733fded4098659e15660ddd7178a`。本轮卡牌数量、价格、收益、技能门槛、维护费、本金及逃离阈值不变；卡牌数值仍由 `data/cardpool-v22.json` 生成。v0.23 改进获取和整理流程。

## 新规则

- **每张展示牌独立计龄。** 连续两周未售出，下周换新；另一时长区或其他展示位的购买不再无限阻止它更换。先抽替换牌，再把旧牌放回底部；供给耗尽时仍可能重新展示旧牌，绝不凭空生成卡牌。原周一无人购买展示牌时整体刷新仍保留。
- **缺成长牌可以主动购买。** 市场上方每色显示下一张未持有、未归档的成长牌，按原价购买，仍需另一次行动安排。使用原有公共供给的实体牌；别人的手牌、归档、完成牌不能被取走。若购买的是现有展示牌，补位和周一标记与普通购买完全一致；从隐藏供给获取不阻止无人购买展示牌时的刷新。
- **未过去日程的移动／撤回免费。** 必须在自己的回合，不能改写过去、突破8h或并行容量，也不能在结算／搜索暂停中改牌。首次安排仍耗一次行动，撤回再放上去也要消耗安排动作。可以免费撤下基础牌，再花一次行动安排升级牌；没有新费用或额外周结步骤。
- **保护目标明确。** 下拉列表展示时段和目标卡，默认不再偷偷选周一。记住上次候选，但每周仍需确认；若上次时段因双休而失效，会回到明确的空选项。一次性卡完成后不会把保护传给同槽另一张牌。
- 使用独立 `escape-velocity-game-v23` 存档；不读取或删除 v0.21／v0.22 存档。导出文件与内容正确标记 v0.23，修复旧版导出仍写 v0.21 的问题。

没有加入支持递减、普通同名牌上限、退出排名、自动判负或新的收入计算。

## 验证范围

- 活跃自动测试 **152 项，全部通过，0 跳过**。原128项仍保留；只迁移版本标签、规则文案，以及“移动需要付费”的回合夹具。新增23项引擎体验测试和1项界面流程测试。
- 新增覆盖：按展示位过期与牌堆耗尽守恒、定向成长的原价／行动／复制限制／错误原子性，2–4人全部座次的四颜色成长断档恢复，三张搬移零付费动作，本金来回搬移不能刷钱，过去／错回合／结算中禁改，基础牌替换，保护候选失效与导出版本。
- 静态组合重算沿用未变的卡池：零技能构筑在两人供应下至少8张，在3／4人供应下至少7张；这不是获取速度或真人胜率保证。没有靠隐藏禁止重复牌来得到此结果。
- 多策略对抗及失败样本见 `experience-baseline-v0.22.json`、`experience-candidate-v0.23.json` 及各自的详细记录。脚本 `scripts/evaluate-experience.mjs` 对相同种子、座次、策略运行真实引擎，不直接赋予成长、资金或终局。
- [最终同策略对照](experience-comparison-v0.23.md)：双方各504个配置，候选495局在30周内结束；展示计龄9→2周，成长在场平均4.82–5.76张，repeat为8.67张；mixed首胜份额仍81.25%，明确保留为未通过的平衡调查项。逐周与逐动作明细使用同名 `-details.json.gz` 保存。
- 自带机器人另跑9局冒烟测试，结果在 `bot-smoke-v0.23.json`；它不代替多策略对抗。
- 本机浏览器工具返回空清单，因此没有声称完成真人网页或视觉验收。DOM测试也不是浏览器实玩。需独立云端验证下面的问题。

## 实玩重点与残余风险

1. 成长入口是否能顺畅解除“差一张成长”的等待，还是让市场选择变得过于固定？每色仅显示下一张，是否足够清楚？
2. 免费整理是否真正减少搬牌负担，同时让升级替换自然发生？首次安排与移动的差别能否一眼理解？
3. 混合路线在自动策略中仍领先；自动对抗的若干两人具体配对仅4–5个种子，不足以证明或排除支配。应优先实玩混合对各纯色，尤其B路线维护负担和多人争抢支持。
4. 坚持永不成长的重复牌策略可能因有限供给分散而卡住；这是保留的压力样本，不能从统计中隐藏。基础优先策略则允许第5周后转成长，符合前次真人局。
5. 有限供给耗尽时，换牌会重新出现旧实体；展示计龄重置与同一UID连续可见是两个指标，报告分别记录，不宣称每两周一定看到新牌。

达到摩擦改善的候选门槛后先交独立实玩；若混合路线、维护或流程问题被复现，继续修改并保留下一次可回滚提交。当前不将候选部署等同于最终体验验收。

## 复验

```sh
npm test
npm run check:cards
npm run build
node scripts/check-balance-v22.mjs
node scripts/evaluate-experience.mjs --output docs/experience-candidate-v0.23.json
node scripts/simulate.mjs --output docs/bot-smoke-v0.23.json
```

对比旧版时，将基线提交的 `src/` 与 `package.json` 导出到独立目录，给同一个评价脚本传 `--engine-root file:///.../baseline/`。不要切换、覆盖或重置当前工作区。仓库未配置 Actions 测试工作流；本地完整测试、部署状态、线上文件一致性分别核验。
