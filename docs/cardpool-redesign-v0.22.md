## 1. 推荐的一套完整设计

推荐 **32种牌：23种4h、9种8h；W9种、A8种、B7种、C7种、共享搜索1种**。不沿用旧ID，也不保留“删后41种”数量。

- 八种成长：每路线两个不同名来源，最高门槛为同色两个技能或两色各一个。
- 四种中阶副业、一种职场现金入口、四种基础副业、八种高级/混合副业、三种纯支持、两个永久权限、一种招募、一种共享搜索；合计32种。
- 入门4h成长和普通小单买价1；商业入口也是买价1，但需另锁本金4。中高级按整个能力重新报价，不实行所有4h统一减1。
- 收入10、理智6作为本轮胜利基准，起始现金8、理智3、周工资3不变。
- 保留现金预留、买牌与安排分开、同名技能只计一次、查岗、成长离场、撤回返本金、两种时间长度。
- 移除灵感指示物与阈值、活动收入骰、下一张加成、按先后触发奖金、自由加码本金及每3/4本金除算、研讨会免费高级牌、多种搜索规则。
- 不新增同名支持递减、定向学习、每人牌数上限、强制技能胜利条件。下文允许同名活动和支持完整叠加，专门检验它们。

这是主动推荐值，尚未得到用户对具体数值的批准。3–6张成长终局活动是示例算出的结果，不是强制目标；归档、权限、手牌不计入“每周活动张数”，它们的前期花费与操作另列。

## 2. 核心预算与结算规则

### 2.1 数值标尺

| 层级 | 基准能力 | 代价与作用 |
|---|---|---|
| 无技能4h | 买1，收入1，压力0 | 便宜启动；继续靠它达10需要大量活动与买/排操作 |
| 无技能8h | 买2，收入2，压力1 | 相对两张小单减少一张实体牌与两次买/排操作，付出压力、整天绑定 |
| 一技能4h | 买3，收入2 | 成长先兑现少一张活动；不顺便赠免费支持 |
| 开发一技能4h | 买3，收入2，压力1，可并行 | 用理智与同日风险换白天空间，收入不乘算 |
| 商业一技能4h | 买3，本金4，收入3，压力1 | 资金被占用，不能拿待收款支持当周费用 |
| 双技能8h | 买5–6，收入4–5，支持/压力各有取舍 | 把多个基础效果合入一张；门槛来自实际归档 |
| 标准支持4h | 买2，支持2，周费1 | 每点支持每周0.5现金，无同名折扣 |
| 压缩支持8h | 买3，支持4，周费2 | 同样的时段与周费换少一张牌，整天易被一次查停 |
| 成长后免费支持4h | 买2，A技能，支持1，周费0 | 每点支持占4h；没有“无技能免费回血”入口 |

购价不是唯一成本。比较一张牌时同时记录：购价、成长净购价、锁定本金、当周已持有的维护现金、买/排操作、占用半天、查岗暴露。不能把可返本金当成花掉的买价，也不能当成仍可消费的现金。

所有普通收益都是固定加法。周末资金 = 成功副业 + 成功普通现金 + 未逃离者工资3 + 适用事件奖金。仅副业计逃离。收入不跨周积累，无收入上限。

### 2.2 夜晚推荐值：4h增加2压力，支持照常有效

每夜最多一张4h，不能放8h，不能夜间并行。额外压力固定2，与卡面压力相加；删除“超过2h支持失效”的旧判断。

理由：起始理智3允许一个零压力成长/小单放夜间，安排后为1；标准支持2放夜间恰好抵消夜压2，净理智为0；免费支持1放夜间净贡献−1。夜晚是安全但损耗理智的时段，不是免费堆支持区域。W履职及职场成长仍只能在工作白天。

成长归档后离开日程，同时撤去它的占时和夜压；不会给技能额外理智。是否能连续安排多个夜晚仍由全局理智非负检查控制。

夜压1会让标准支持在安全夜晚净赚1理智；夜压4会让起始3理智连零压力成长都放不进去。因此本提案选2，不把此前讨论的1当已批准结论。

### 2.3 并行、支持、本金

- 只有B-M和B-X具有并行。仅白天，同格最多两张4h，其中至少一张有并行；8h不参与。两张并行牌也只能叠两张，不能递归扩容。两个收益分别相加，费用、压力、罚款各算。
- 一张8h占两个半天、只执行一次。删除8h卡下再分上午/下午放附属卡的操作。
- 理智 = clamp(3 + 自主 + 有效支持 − 印刷压力 − 夜压, 0, 10)。双休自主+2，逃离后仍沿用原规则；支持不逐周积累。
- 同名支持全额相加，不做递减。被查停/团建的支持不生效也不收费；被查停牌仍留在日程，印刷压力不消失，沿用现规则。
- 支持费用在查岗揭晓后、普通收益入账前支付；无钱则沿现有日程顺序撤回。界面显示一份“本周维护总额/已预留”清单，正常情况不用逐牌弹窗；不另加费用优先级子游戏。
- 商业仅保留印在牌上的固定本金4/6/8。安排时锁定，撤回/离场原额返还；没有调节金额、部分份额、收益除法。复用现有capital路径，不用capitalRatio。
- 全牌理智门槛统一0–10；仍检查安排后理智不能负数。结算中的支持丢失会降低最终理智，却不会触发一连串收入牌低/高理智门槛失败。

### 2.4 市场、搜索、招聘

- 仅4h/8h两个牌堆，明牌6/4张，共10张，购买即补；周一无人购买则沿用整批刷新。4h成长/起步种类较多，多给展示位；8h留4位让压缩牌被看见。
- 非高级每种N张；八种高级/混合每种ceil(N/2)张，N为人数。2/3/4人实体总数56/88/112。技能仍由不同名决定，多份供给不增加技能上限。
- 一次性共享S-Q：买价1，安排4h，执行时选一个暗堆，看3，原价买至多1，其余回底，所得下周安排。执行后本工具离场回弃牌，不留下技能；即使空堆/放弃也消耗工具。无重抽/排序/免费赠牌。买工具、排工具共两次行动，换取访问更多候选。
- C-U招募仍为常驻：需C，购价2，每次执行可从明牌买一张4h成长牌，付原价+1直接归档，不执行返现。只显示尚未归档、且未在自己手牌/日程中持有同名的目标；不允许永久权限或S-Q。取消/无目标不收招聘费。
- 招募不保留“仅market[2]”限制。目标可来自所有市场中符合条件的牌；当前八种成长均为4h。它省后续成长的单独安排行动，但多占一张常驻牌、现金与4h，适合跨路线；只招一张通常不划算，不伪装成必买核心。
- 市场抽样仍有随机性，技能来源充足不等于保证按时拿到。不新增定向学习或个人预留牌；需实测市场卡手率。

## 3. 全部32张明确清单

表内“现”=普通现金，不计逃离；“收”=副业；“维”=每周维护。无额外条件、无随机收益、capitalRatio=null、理智范围0–10是每一张牌的共同字段，不存在未列出的旧效果。

一次成长成功后只归档本路线1技能，同名只计一次；第二类成长的返现1在周末领取。权限的“次费”每次成功推进即时付，且每周最多推进一次。完整机器字段（包括0/false/null）见cardpool.json。

## 6. 专门反例：基础重复铺牌与同名支持

### 6.1 零技能完整枚举边界

枚举所有无技能且能贡献副业/支持的常驻牌：A-E、B-E、A-L、C-E、B-S、W-S；每种最多N张，允许某玩家拿走全场该种供给。同名支持全部有效、可用整个14个白天半槽与7个夜晚、忽略查岗/团建、现金无限。纯工资牌、搜索、招募不改善最终收入/理智可行性，因此不作为终局组合元素；它们可能加快获牌，这是本静态枚举未覆盖的部分。

遍历每种牌0..N份；检查收入≥10、理智≥6及4h/8h排布容量，夜压按2计算。没有把“7–9张”写进约束。

| 人数 | 遍历重数组合 | 最少活动张数 | 最少牌数下的最低购价+本金+首周费 | 所有组合最低资金占用 / 对应张数 |
|---|---:|---:|---:|---|
| 2 | 729 | 8 | 26 | 21 / 9张 |
| 3 | 4096 | 7 | 26 | 18 / 9张 |
| 4 | 15625 | 7 | 23 | 15 / 10张 |

结论：这套候选数值**没有禁止零技能逃离**，而是让它至少承担7–8张、更多时段与维护；支持叠加没有把它压缩到3–6张成长示例。但“零技能不是最优策略”还没有得到证明。

必须保留的危险反例：四人供应下，A-E×4+B-E×4+A-L+W-S共10张，收入10，压力1，支持4，理智6；购价13、维护2、无本金，只需15的资金占用。其成本比部分成长版图低，代价是至少20个买/排操作、12个白天半槽和每周2维护。纯A后期示例虽筹建占用18，却仅8张累计必需购入（含两成长）、至少16个买/排操作，7个白天半槽、无维护。它们谁更早逃离必须用同种子、同事件及实际购买流程比较，不能靠静态价差判胜。

本轮不为掩盖这一风险增加统一生活费、技能胜利门槛或同名递减。如果实际对局仍显示廉价基础稳定抢跑，首先调整基础8h的收入/压力或高级取得成本、并检验市场供给，而不是悄悄加入新胜利条件。

### 6.2 同名支持不能免费填夜晚

- B-S每张支持2/周费1/4h；夜晚压力2，净理智0。重复堆夜晚不会提高最终理智。
- W-S支持4/周费2/8h；两张合计支持8/费4/16h；只能占白天，可被查岗一并停掉。它能让零技能达到理智线，但有明确现金和空间成本，枚举已允许最多N份。
- A-S支持1/无周费/4h，但需要A技能；夜间净理智−1。三张在白天确能补足基础理智3到6，这是成长后的空间换费用，不属于零技能漏洞。
- 不使用同名支持递减或同名上限，避免多一套例外。若用户后续明确要求彻底禁止零技能通关，那是不同设计目标，需要明确批准规则变化。

一技能W/A/C可以以6张结束，说明不必强迫所有玩家升满；B第一技能主要省时段，并不自动减少终局张数，第二技能与混合牌负责收入压缩。这是需要优先试玩的薄弱点：B是否感觉前期付出多而兑现慢，不能只看并行图标就判强。

## 10. 已知边界与本次不包含的内容

- 已完成的是字段一致性、技能可达性、具体日程容量、收入/理智/本金/周费、零/单技能重数边界和给定排布查岗枚举。新卡池没有接入真实引擎，**没有新版整局模拟、胜率、平均周数或真人用时证据**。
- 购价相近不代表公平：W权限改变安全时段；商业本金影响现金速度；搜索影响获牌；成长会归档退场；同名牌被多人抢夺。静态表无法覆盖这些动态因素。
- 2人高级每种一张、3/4人每种两张可能导致多人追同一路线卡手；这是优先观察项。必要时首先调供给/展示，而不是编造定向学习已获同意。
- 最终按逃离顺序排名、逃离者不再行动、同周逃离如何并列，是独立可选终局改造。当前仍沿用N−1人逃离当周结束；本卡池提案不自动包含终局修改。
