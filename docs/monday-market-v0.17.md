# v0.17 · 周一无人购牌刷新

周一所有玩家行动结束时，若没有尚未逃离的玩家购买公共市场牌，立即整批刷新公共市场，再正常进入周二。每周最多触发一次。

- 安排、移动、撤回、躺平和购买个人项目均不阻止刷新。移动日程无法否决市场更新。
- 任意一名在职玩家成功购买一张公共市场牌，就保留本周市场；购牌失败不计数。已逃离玩家的购买不影响判定。
- 暂时移开全部旧明牌，从对应的 2h、4h、8h 牌堆补出 5、4、3 张。沿用正常抽牌的弃牌回收规则，再把旧明牌放回对应牌堆底。牌源不足时，允许旧牌补足空位。
- 刷新免费，不额外获得行动或资金。其他日子无人购买不触发这条规则。

网页在周一显示是否已有购牌、是否将触发刷新，并将实际刷新记入日志。v17 存档保留周一购买状态；每周重置，需要新开一局使用本版。
