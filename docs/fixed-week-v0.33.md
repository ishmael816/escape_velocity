# v0.33 固定周流程

本次只改周流程、市场刷新时机与待买区，沿用 v0.32.2 卡牌数值。

| 阶段 | 每位未逃离玩家的操作 |
| --- | --- |
| 周一 | 买一张市场牌或自己的待买牌，也可跳过 |
| 周二 | 买一张市场牌或自己的待买牌，也可跳过 |
| 周三 | 移动、撤回已有日程，可调整多张，点击完成调度结束 |
| 周四 | 安排一张手牌，可先撤回旧牌腾位置，也可跳过 |
| 周五 | 安排一张手牌，可先撤回旧牌腾位置，也可跳过 |
| 周末 | 按资格依次保留市场牌，然后锁定日程、查岗、结算 |

先手用火箭在自己的玩家提示板上指向当天。每周从周一开始，所有未逃离玩家从先手起依序行动。等每个人都完成或跳过当天行动，先手再将火箭移到下一天。周五行动结束后，先手翻到提示板背面，组织保留市场牌和结算。若游戏继续，将火箭交给下一位仍在场的玩家，由其主持新的一周。

全员跳过仅进入下一阶段，不提前结算。阶段名称与牌的目标日期无关，周四可以安排到周一。旧牌移动只在周三进行。周三不直接打出手牌。

周一全员未购买时，每人依次获得一次可选刷新，可选一整行 I 级或一张 II 级。等大家都刷新或跳过后，先手才把火箭移到「周二」。刷新对象保护至下周，不能被其他玩家刷新，仍可购买或保留。购买待买区牌同样算周一购买。

## 实体市场摆放

- Ⅰ级牌按履职、创意、技术、商业分成四堆，分别洗匀，牌面朝下放在版图右侧对应列顶端。每堆向下翻开两张。同列的牌被购买或保留时，从该列牌堆补空位。
- 刷新Ⅰ级的一整行时，同时移开该行四张旧牌，从四个流派牌堆各翻一张。旧牌各自放回所属流派的牌堆底。
- Ⅱ级牌混洗成一堆，放在左下角，向右翻开四张。左上事件区从左到右依次为事件牌堆、本周事件和事件弃牌。活动弃牌按等级放在版图旁。

## 待买区

- 周日上午没有活动占用时可以锁牌；永久双休后，空置的周六上午也提供资格。临时双休不增加此资格。
- 两个上午都空闲仍只保留一张。II 级活动覆盖上午时，该上午不空闲；后续查停也不返还锁牌资格。
- 从公共市场拿一张放在个人待买区，立即补位；无须先满足价格或技能，不付钱。
- 每人最多一张，跨周保留。只有主人可在周一、周二按正常条件购买，占一次采购机会。
- 未买下前不能丢弃、替换、安排或转化；买下后待买区腾空。
- 锁牌可以跳过；本周安排完成的快捷操作仍会停下来让人选择锁牌。
- 结算阶段由卡牌触发的搜索与购买继续按卡面执行，所得手牌下周可安排。

## 存档与验证

使用独立键 `escape-velocity-game-v33-fixed-week`，旧局保留。引擎存档带 `planningModel: fixed-week-v1`，卡池数据版本仍是 32。

- 96 项规则、卡牌与界面测试通过；卡池生成一致性及静态构建通过。
- 专项检查覆盖固定阶段限制、周一刷新、自由调度、整周安排、永久/临时双休、II 级占用、待买区持久化、技能/资金检查与保留后补牌。
- 实际浏览器走通首周采购、调度、周四将牌安排到周一、周五跳过、周末保留、查岗与结算，以及第二周正常购买待买牌并腾空待买区。
- 9 局启发式机器人对局（2–4 人，各三个种子）均持续推进，没有规则异常或行动死循环。5 局在 15–35 周结束，4 局达到 35 周测试上限仍未结束；这是测试上限，游戏没有固定周数。
- 机器人结果不能证明新版节奏与路线平衡；多人局收尾速度还需真人复测。本次没有为机器人结果调整牌值。
