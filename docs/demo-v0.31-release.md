# v0.31 demo 实装说明

2026-10-14。将 v26–v31 讨论的候选机制接入可玩 demo；数值仍是待真人验证的首轮版本。

## 卡池与路线

整池替换为 38 种、每种固定 4 张，共 152 张。只保留 4h / 8h 两个牌堆，展示 8 / 4 张。完整数值见 [卡池表](cards-v0.31.md)，数据源为 `data/cardpool-v31.json`，运行 `npm run generate` 同步代码和表格。

- 职场：低理智奖金、骰子奖金；投入多周争取弹性授权或双休，之后转型。
- 创作：主动付费生成版图灵感；灵感门槛维持写作/绘画收入；消耗灵感取牌，再以弃手牌兑现收入。无自动灵感。
- 开发：白天两张 4h 并行；产品前两次成功执行为低收入，第三次起成熟，被查停不推进。
- 商业：固定锁 4 本金，撤回返还；招募明牌/自有手牌成长，猎头从 4h 暗堆找成长。招聘支付买价、完整进度费和 1 服务费。

不增加分支标签或套装资格。绘画骰子牌与改稿交付的买价为本轮候选值；尚无对照实验支持“已经平衡”。

## 共同规则

4h 夜晚理智成本改为 −1；周日全天仍 −2。查岗采用公共骰、各玩家独立追查：命中当天摸鱼则暂停并继续，空日/已查日退出这一轮；每张命中牌罚 1，8h 不重复罚。

灵感生成、消耗、弃牌均为可选结算选择。取牌统一看 3 取至多 1，其余弃置；普通搜索付原价，素材笔记免买价但仍检查技能；新取得牌下周才可安排。支持为日程结构性理智影响，不按周累加；查停或付不起支持费用会解除效果。

沿用工资 3、初始现金 8、理智 3；实际副业 ≥10 且理智 ≥6 逃离；职场奖金、工资不计门槛。沿用已安排牌的免费整理、全员同日躺平提前周结、逃离者退出和 N−1 人逃离结束。

新版使用独立 v31 存档键，保留旧存档但不迁移旧卡牌。请开新局测试。旧打印套件没有同步重制。

## 验证与局限

63 项自动测试全部通过，覆盖固定供给、成长费和进度、追查退出、理智与支持、本金退回、灵感生成/清除、搜索/招聘、产品成熟、存档重载，以及界面选择。旧卡池专属测试保留在 `tests/legacy-v24/`，不作为新版通过数量。

完成 2/3/4 人各 3 个种子的机器人对局（7、42、20261009），9 局均自然结束。结束周数分别为：2 人 12/11/12，3 人 21/22/12，4 人 21/26/23。部分逃离者现金超过 100，说明长局现金积累仍需检验。机器人表现不能证明真人节奏或流派平衡。

网页实测完成购买、安排、自动跳过、结算停在搜索选择、购买候选并恢复周结总账等流程，浏览器未报告脚本错误；引擎测试覆盖可选活动与存档恢复。构建检查卡表与源数据一致。
