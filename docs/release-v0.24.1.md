# v0.24.1 / C4：消除抵消项、提高搜索投入、减少重复跳过

基线为 C3 / `7ca83a1a909e8cab227a62e5a6c72d9c966e61c0`。这是供下一轮网页实玩的候选，不是最终平衡认证。本轮只改变三个卡牌数值字段和一个自愿操作流程。保留原卡池供给、重复牌、自由兼修、本金、夜间压力与N−1终局。

## 本轮变化

**软件订阅 B-H：支持1/压力1 → 支持0/压力0。** 买价6、BB前置、8h、收入5、维护0不变。它是全卡池唯一同时具有正支持与压力的牌。正常生效净值相同；旧版被查岗或团建暂停时，支持取消而日程压力保留，新版不再有这项额外理智损失。因此每张暂停的软件订阅比旧版多保留1理智，属于小幅抗风险增强，不能说完全等价。查岗仍停收5收入、罚款1，8h只处罚一次。正常有效盘面的安排门槛、移动与撤回净理智不变；已知暂停或不具备技能的异常盘面也不再承受那1点压力。团建仍禁止新安排，BB与8h容量门槛不变。

支持在查岗揭晓后、活动收入到账前确认，压力由日程持续计算；本次没有改动这套全局规则，也没有给软件订阅增加例外。软件订阅维护0，不存在它自己付不起维护的分支；其他付费支持仍可能在收入到账前因现金不足撤回。预览仍不预测隐藏查岗日期，不能将无查岗的净零预览视为保证收入。

**寻找机会 S-Q：买价1 → 2。** 保留4h、一次性、自由选4h/8h堆、看3按原价买至多1张、其余归底、下周才能安排。购买搜索牌和安排搜索牌仍各花一次行动；执行中的候选购买不额外花规划行动，但要付目标原价。获得并安排目标总共通常需三次规划行动，直接购买并安排则是两次；搜索的优势是额外看牌与选择，不能仅凭已有行动成本就否认它可能成为通用必抢。

所有方案24/24结束。一张搜索已购买但尚未执行，可使执行次数小于购买次数。选价格2是最小资金调整：与一次成长买价相同，保留找牌功能。价格3进一步挤压买目标的现金，看2主要降低命中而购买数变化小；固定单堆会削弱通用补救，人人可用的基础搜索则扩大可用次数并改变行动流程，本轮均不叠加。

价格2的二人各座位购买数为3/1，三人为1/5/4，四人为4/6/6/2；每种人数只有8个种子，不能宣称座次绝对公平。机器人在440次“看得到且买得起、未持有搜索”的回合中394次选择其他付费行动或跳过，说明其策略存在不拿的局面，**不证明真人不会必抢**。机器人对搜索有固定启发式评分，并非完整价值模型；下一轮要看玩家面对成长、直接买目标和搜索时是否真正有取舍。

**本周安排完成：自愿确认后的快捷跳过。** 先展示预测、查岗/搜索不确定性、未安排手牌、当前不能生效的支持和未确认保护，再确认跳过。只替该玩家执行本周剩余的普通跳过，不代购、不安排、不改变每日行动数；其他未确认真人照常行动。期间可取消；打开帮助、图鉴等弹窗会暂停，关闭后继续。读档保留意图但先暂停，需要点击继续或取消。到结算前停止，掷骰、搜索、逃离与进入下周仍需玩家操作。下一周意图自动失效。

原实玩每周安排完后仍要连续点击4–7次跳过；新流程用入口和明确确认两次点击表达本周意图。DOM回归验证了控制边界，尚未把它当作已完成真人视觉/交互验收。

## 双软件订阅与本金审查

实玩观察是四人B局第5周以软件订阅×2＋完整休整三张活动，收入10、理智7、维护2逃离；第4周被查一张，收入损失5未逃离，另一个AI第5周也逃离。这支持构筑可行，不能据此称人类单边碾压。

只隔离B-H净零修改，56个同种子、轮换座次的三/四人配置均结束。B策略56个位置中45个最终盘面有双订阅，说明它是常用路线，值得继续调查；B首胜份额37.20%→40.48%，尚无全面支配证据。三张构筑购买总价15、另需两张不同名B成长和四次成长获取/安排行动；至少一张8h收入牌通常暴露于工作日。新回归明确验证：一张订阅被查后只收入5，仍不能逃离。此次没有通过禁重复掩盖供给或强度问题。

本金本轮不改。24个含C/混合的实际引擎探针中出现7次本金撤回，2次随后同周再消费；只有1例后续资金门槛确实需要此前返还。具体为两人种子11、C位第4周：现金9，撤回返还2→11；购入花5、安排锁4后剩2，再购2价牌；若本金不可退，最后这次购买资金不足。这证明有真实调度用途，但使用频率有限，不能据此证明额外记账总是值得。长期持有到胜利时，本金与更高买价的实际差别很小；保留为后续简洁性审查项，不用主题解释替代证据。
