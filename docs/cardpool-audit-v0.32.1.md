# v0.32.1 全卡池审阅

日期：2026-11-03。核对 `data/cardpool-v31.json` 全部56种、224张卡，以及实际结算代码。此稿是审阅和修订方向，不修改游戏卡值。I级=4h，II级=8h。

## 口径与证据边界

- 资金是实体资源；副业收入是当周生效卡牌的属性汇总，不是领取、储存或跨周累积的资源。
- 分开记录：购价、永久消耗、可回收但需另行卖出的本金、持续费用、技能前置、时段、理智影响、收入、其他资金。不能把可出售本金全部当成已经损失的购价，也不能忽略其占款。
- 旧稿 `P/3+h/4` 与理智边际价值2只作筛查，不作为已经校准的现版本定律。技能共享、指示物供应、查岗追查、周日占满惩罚都会改变价值。尤其不能把辅助牌全额成本重复分摊给每张终端牌。
- 同等时长比较两张I级和一张II级，但注明两张牌的购买/安排行动、牌数与市场获取差异。一张II级少一次罚款、难以分散时段，不能简单视为完全等价。
- 全部判断为静态结构审阅。没有据此宣称某路线实战胜率最高，也没有进行新的完整真人对局。

## 核验的反例

运行 `node scripts/audit-cardpool-v32.mjs tmp/cardpool-audit-v32.json`。

已购盘面：零散开发3张、小本生意2张，分布于周一上午/下午、周二上午/下午、周三上午；下楼遛弯4张，分布于周一至周三夜晚和周日上午。份数合法，技能0。

- 总购价27；另备当周执行资金8。此处直接构造已完成购牌的中盘，未模拟筹资和逐日购买过程。
- 无查岗、无团建事件：收入10；理智=3+8−3=8；维持费8；工资3，周现金净增5。实际引擎判定可以逃离。
- 收入牌暴露于三个工作日，有真实查岗风险；集齐四张同名支持也有公共市场竞争。因此它证明零成长逃离组合存在，不能证明平均很快或最强。

## 首要结构问题

1. 零散开发、小本生意均为买3、I级、无技能、收入2；专栏写作买4却只有1/高理智2。基础牌内部已不齐。
2. 自动补货买6、BC、两个本金启动需额外4–8钱，合计10–14钱；未自动时收入2，满载自动才3。本金保留资产价值，但它仍要额外占款、成长、自动来源和整日时段。两张基础牌仅6钱、同样8h、收入4。差距不能只靠少一次购牌行动解释。
3. 云端托管只需B、I级、买3并消耗1本金，收入3。默认汇率下直接投入6钱，但本金须通过其他牌先取得。企业团购买6并消耗1本金、WC、II级，仅2/高理智3，成长回报明显倒挂。
4. 集中攻坚：买3、两次安全执行，完成5钱+永久履职2+W；工作交接：买2、两次各付2，分别给履职1+最终W。工资用途下两周结束，不含公共基础工资，前者累计净现金+4、后者−3，差7；交接只多第一周的提早保护选择。归档同名不重复算技能，但现金/履职奖励可重复。
5. 副业条件中，骰子、已经消耗的灵感、临时指定的下邻加成、执行后移动的自动标记，都可能在周末无法从版图还原。程序的 weeklyEarnings 日志在替玩家记账，不等于实体规则已简化。
6. 创作过牌后缺少明确的手牌转化端；成长归档也很不均匀，卖课在零归档时仍可买4+执行1、一周取得B，快于两周总价6的买课。不能孤立评价买课与学习技术。

## 收入必须从实体状态读出的修订原则

固定收入、牌上本金/封存灵感/履职数量，以及仍在场的相邻关系可以读出。骰子结果、已消耗材料换来的临时副业、执行后改变的成熟状态不能自然留在版图上。建议：

1. 副业值优先由牌面固定值与可见的现有状态决定；资金额外收益可以掷骰或消耗材料取得。
2. 有费用的收入牌只需保留全游戏统一的“本周生效/暂停”状态；避免为每种牌增加临时收入数字或专属计分轨。
3. 成熟、自动消耗等改变状态的牌需要统一判定时点；不能假设最终版图必然等于执行时版图。
4. 不为简化而偷偷增加副业轨道。修改骰子牌时重算固定收入与随机资金总期望，避免双重发钱。

## 建议修订顺序

先校准B03/C02/B13与II级的共同效率关系，再修W04/B11的成长入口，然后重定C12/C06/B10/W16及混色终端，最后统一过牌与材料转化收益。

II级主力收入大致2–3、特定组合可到4，与“三四张主力构筑才过10”的目标较相容，但这只是候选区间，不能替代全盘组合测试。不能同时保留无限制廉价I级收入2与昂贵低密度II级，再靠给后者更多技能要求制造层次。

完成新数值后应以同种子/座次分别比较：基础收入铺场、履职工资转型、灵感抽牌、自动联动、本金经营；记录首次技能/首张II级/收入与理智同时达标周、空过比例、有效购牌数、结余和查岗损失。目前没有这些新实验，故不宣称调整量已验证。
