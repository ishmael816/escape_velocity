# 逃离工位 v0.5 · 59 种卡池

直接从 src/cards.js 生成。卡面牌种与效果全部公开；公共市场和高级牌库的顺序隐藏。高级牌通过活动寻访取得，没有额外购买费。

基础重复经营净值为 2/3/4，高级三技能重复为 4/6/8；按资金+理智+2×灵感计算。净值不含首次买入费、技能、抽选、成就或永久能力。连锁牌按本周一次收入加成计入；不触发就得不到这部分价值。成就另行用 3 点经营预算换 1 点，尚需测试。
