完整九场自动对局中，仅 2 人、种子 42 在第 34 周结束，其余八场达到 35 周测试保护上限，因此模拟脚本返回失败状态。这个上限不是游戏规则。自动对局说明现有机器人与规则组合仍有明显停滞，不能直接预测真人胜率或时长。
