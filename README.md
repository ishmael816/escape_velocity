# 逃离工位 · 网页试玩版 0.19

实体桌游规则验证版，支持 2–4 人同机轮流或自动玩家。统一数值模型、混合收入支持和分档生活消费已接入；仍需真人测试卡池节奏与路线平衡。

## 启动与部署

需要 Node.js 24+，无第三方依赖。运行 `npm run dev`，打开 http://127.0.0.1:5173/ 。仅监听本机。

`npm run build` 生成 `dist/` 静态站点。Vercel 使用仓库内 `vercel.json`：Other 框架、构建命令 `npm run build`、输出 `dist`；生产分支以部署项目设置为准。本地修改不会自动部署。

## 第一局

1. 周初公开事件，查岗只预告次数。每天玩家轮流各行动一次，周一至周日共七次；每周轮换首位玩家。
2. 一次行动选购买一张牌、安排/移动/撤回一张牌，或躺平。躺平仅跳过行动，不获得资源，已安排活动照常结算；不再允许指定刷新市场明牌。购买与安排分开，只能调整今天及以后时段。
3. 2h、4h 各占一个白天槽；8h 跨上午与下午，下午执行一次。夜晚最多两张 2h 或一张 4h；4h 夜晚额外承担 4 压力。
4. 理智为 0–10 指标，起点 3；永久双休增加自主状态 2，逃离后自主状态改为 4，不叠加。加入有效支持牌贡献，再减日程压力。支持牌不逐周累加理智：查岗揭晓后、普通活动执行前支付本周维持费；费用不足则撤回手牌；被查停、团建阻断或当晚安排满 4h 时支持失效。混合支持牌继续按日程执行其余效果。门槛在安排后与执行时检查，没有每周工作日扣理智。
5. 市场只有 2h/4h/8h 三堆，展示 5/4/3 张，购买即补。周一全员行动结束时，若没有尚未逃离的玩家购买公共市场牌，整批刷新市场；安排、移动、撤回、躺平不阻止刷新。先补新牌，再将旧明牌放回对应牌堆底；牌源不足时用旧牌补足。高级牌混在 8h 堆，可先购买，满足归档技能才可安排。职场 W、创作 A、开发 B、商业 C；同名归档不重复计技能。
6. 全员日程锁定后掷公共查岗骰：1–6 对应周一至周六，检查当天上午和下午；重复不重掷。每张被抓活动本周暂停、罚 1 钱，不按时长加罚，没有额外理智处罚，但被查停的支持牌失去本周贡献。8h 占两槽仍只罚一次。履职牌与休息时段不受查岗。
7. 按日程顺序执行活动，征稿与代购固定收入，只有一次性向上管理保留奖金骰；重复活动付不起执行资源时撤回手牌，解除支持与压力并返还本金；所有活动资金收益暂记，日程全部结束后与固定工资 3 钱、事件奖金统一领取，无生活费。当周待收资金不能支付后续活动或找牌购入；灵感仍即时获得，费用仍在执行时支付。工资与奖金不计逃离，当周副业达到 10 且理智至少 6 可以逃离（先检查，再获得逃离自主状态），无副业轨道：成功副业在周末合计，实际收入不封顶。N−1 人逃离的当周结束；其余玩家为“究极牛马”。
8. 四色一次性找牌活动在执行时暂停结算：选一个暗牌堆、公开候选、原价购买至多一张，下周才能安排。普通余牌放堆底，开发牌可整理堆顶与堆底。场上明牌不受影响；不买也归档，无空堆补偿。旧研讨会与猎头仍在周末免费取得指定高级牌。

默认开局 8 钱、3 理智、4 灵感，活动手牌、活动日程和技能区均为空；活动须从公共市场购买，再花行动安排。已安排的常驻牌跨周保留。商业本金在安排时锁定，撤回返还；绿色增强只作用于紧接的一张活动，不跨周叠乘。

“争取双休”和“弹性工作授权”分别进入 8h、4h 公共牌堆，通过市场或普通找牌活动取得。购买无需技能，安排时检查职场信用。双休需三次成功推进；完成后从日程移到永久效果区，不增加 W 技能。没有个人保留牌或固定购买入口。

## 数值与验证

- [v0.19 接入与试玩报告](docs/economy-runtime-v0.19.md)：基础模板、生活费用、混合支持与测试边界。
- [v0.19 全卡池校对](docs/card-audit-v0.19.md)、[计算明细](docs/card-audit-v0.19.json)、[当前卡池](docs/cards-v0.10.md)。旧文件名沿用，内容为 v0.19。
- [9 局逐周经济数据](docs/simulation-economy-v0.19.json)、[查岗与奖金骰概率](docs/dice-check-v0.10.md)。
- 历史设计：[v0.18 模型](docs/economy-model-v0.18.md)、[v0.18 公共权限](docs/public-permissions-v0.18.md)、[v0.17 周一刷新](docs/monday-market-v0.17.md)、[v0.16 总账](docs/weekly-bill-v0.16.md)。冲突以当前报告和运行时为准。

112 项规则测试、卡池结构、数值预算与静态构建通过。9 局自动对局全部结束，10–18 周，首周每人采购 2–4 张。逃离时现金仍为 14–38，末期积累尚未解决。机器人不能验证真人平衡或游戏时长；35 周只是测试保护上限，游戏没有固定周数。

复现卡池：依次运行 `node scripts/design-cardpool-v10.mjs`、`node scripts/export-runtime-v10.mjs`。模型调整集中在 `scripts/calibrate-cardpool-v19.mjs`。验证：`npm test`、`node scripts/check-cardpool-v10.mjs`、`node scripts/check-dice-v10.mjs`、`node scripts/audit-cardpool-model-v19.mjs`、`npm run build`。模拟：`npm run simulate -- --output docs/simulation-economy-v0.19.json`；加 `--matrix` 可覆盖 36 局。

v0.19 使用独立存档，需要新开一局；旧存档保留。刷新可续局，周一购牌记录、骰子、找牌候选、付款与整理顺序保持；可导出 JSON 复盘，暂不支持导入。旧对局不能代表当前规则。

## A4 与主要文件

`output/pdf/` 和打印脚本仍为 **v0.6 归档**，不适用于当前规则，本次未重制图纸。卡面沿用已有图标与角标素材，见 `assets/card-ui/`。

- `scripts/design-cardpool-v10.mjs`：卡池数据源；生成 `docs/cardpool-v0.10.json`，再导出 `src/cardpool-data.js`。
- `src/cards.js`：运行时适配、事件与默认参数。
- `src/engine.js`：行动、结算、骰子、自动玩家。
- `src/app.js`、`src/card-face.js`、`src/v10.css`：玩家板、卡面与骰子界面。
- `src/opportunity-ui.js`：找牌候选、购买与整理堆顶/堆底界面。
- `tests/`、`scripts/simulate.mjs`：规则与自动对局验证。
