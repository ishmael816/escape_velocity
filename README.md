# 逃离工位 · 网页试玩版 0.20

实体桌游规则验证版，支持 2–4 人同机轮流或自动玩家。当前版本接入自选本金、雇人归档、版图灵感、开发并行和重复找牌；数值为首轮校准，仍需真人测试。

## 启动与部署

需要 Node.js 24+，无第三方依赖。运行 `npm run dev`，打开 http://127.0.0.1:5173/ 。`npm run build` 生成 `dist/` 静态站点。Vercel 使用仓库内配置；本地修改不会自动部署。

v0.20 使用独立存档，需要新开一局，旧存档保留。刷新网页可续局；可导出 JSON 复盘，暂不支持导入。

## 第一局

1. 开局 8 钱、理智基准 3，手牌、日程和技能区为空。周初公开事件，查岗只预告次数。周一至周日，每天玩家依次各行动一次，每周轮换先手。
2. 一次行动选择买一张牌、安排/移动/撤回一张牌，或躺平。购买和安排分开，只能调整今天及以后时段；躺平不给资源。同一天所有玩家躺平，立即结算整周已安排的日程。
3. 市场按 2h/4h/8h 展示 5/4/3 张，买后立即补。周一无人购买公共市场牌则整批刷新；先取新牌，旧牌回底。高级牌按实际时长混在三个牌堆中，可先买，安排时检查技能。
4. 工作时段直接摸鱼，夜晚直接安排活动，无需先买时间权限。普通 2h/4h 占一个白天槽，8h 跨上午和下午并于下午执行一次。普通夜晚容纳两张 2h 或一张 4h；满 4h 增加 4 压力且当晚支持失效。
5. 理智为 0–10 状态：基准 3，加自主与有效支持，减日程压力。支持不逐周累加。双休永久增加自主 2，逃离后自主改为 4。查岗揭晓后、活动执行前支付生活支持费，付不起则退回手牌并撤回效果；被查停或团建占用的支持失效。
6. 日程锁定后掷公共查岗骰，1–6 为周一到周六，查当天上午和下午，重复不重掷。被查到的活动本周暂停并罚 1 钱，8h 只罚一次。职场工作牌和非工作时段不受查岗。弹性授权只保护选定时段的一张符合要求的活动。
7. 按日程顺序执行活动。重复活动付不起费用则回手并撤回效果、返还本金。活动收入暂记，周末连同固定工资 3 和事件奖金领取；待收款不能支付当周费用。没有生活费。结算副业收入至少 10 且理智至少 6 可逃离；工资与奖金不计逃离，收入没有上限，也没有独立副业轨道。N−1 人逃离的当周结束游戏，其余玩家为“究极牛马”。
8. 一次性成长完成后进入技能区，同名只计一次。双休与弹性授权从公共牌堆取得，需相应职场技能和多周推进，完成后进入永久效果区；没有个人固定项目或开局赠牌。

## 新机制

- **商业本金**：稳定供货每 4 本金产生 1 收入，自有品牌每 3 本金产生 1 收入。安排时自选整份金额；本金压在牌下，不能再消费，撤回返还。调整本金消耗一次安排行动，不设收入上限。
- **雇人**：招募伙伴每次可从明牌买一张 2h 一次性技能牌，付原价 +2，直接归档，不执行原牌效果。同名技能不能重复购买归档。
- **版图灵感**：每周开始在每个空夜晚放一个指示物；创作检查数量，不消耗。放牌即清除该处指示物，当周撤回不补。最多七处，不另维护灵感货币。
- **开发并行**：四张中高级开发牌自带并行，允许同槽有另一张活动，最多两张，时间取较长者，压力、费用与查岗各算。2h+2h 并行仅占 2h；4h 夜晚仍有熬夜处罚。8h 跨两格，两个半天分别检查容量。
- **重复找牌**：四条路线各有一张，另有商业 C07。执行时选一个暗牌堆，看指定数量，最多原价购买一张，余牌回底；所得下周安排。商业找四张另付 1。没有余牌排序或重抽。研讨会与猎头仍从未亮出的对应高级牌中二选一，不再假定高级牌全在 8h 堆。
