# 逃离工位 · 网页试玩版 0.24.2

**本版重做收入预算。** 以需要技能投入的4h收入2、8h收入3为基准，再按支持、并行和本金调整。目标是三至四张主力活动构成逃离引擎；“高级”不是正式等级，全部卡牌仍仅按时长分池。见 [数值设计与验证边界](docs/income-budget-v0.24.2.md)。

32种卡牌，只有4h与8h。入门成长买价2；通过成长把多张小单替换为更少的主力活动。支持2–4人同机轮流或启发式自动玩家。

## 启动与发布

Node.js 24+，无第三方依赖。`npm run dev`后打开 http://127.0.0.1:5173/ 。`npm run build`检查卡池一致性并生成dist；Vercel按vercel.json发布静态站点。线上`/version.json`可核对版本和提交SHA。

v0.24.2使用独立存档键，需要新开局；旧版本存档保留。刷新可续局，可以导出JSON，暂不支持导入。

## 本版规则

- 开局8现金、理智3、空手；每周工资3，无生活费。买牌和安排各一次行动，每人每天一次。
- 4h市场6张、8h市场4张，购买后补位；周一无人购买公共牌则整批刷新。
- 夜间仅一张4h，额外压力2，支持照常有效；8h独占白天。并行仅白天两张4h，其中至少一张有并行图标。
- 每路线两个不同名成长来源，归档后离场；同名技能只计一次。按每张牌的技能图标检查能否安排，不另分等级。
- 支持不逐周积累，维护在收入到账前支付；付不起则撤回。商业锁定固定本金，撤回返还，不能使用待收收入支付本周费用。
- 收入固定相加；取消灵感、活动骰、下一张加成、顺序奖金和可变本金除法。共享一次性搜索看3买1；招募明牌4h成长，原价+1直接归档。
- 查岗骰日程锁定后掷，1–6查周一至周六白天；重复不重掷，被查牌暂停且每张罚1。职场履职免查岗。
- 当周实际副业至少10且理智至少6可逃离；工资、现金奖金不计门槛。逃离后退出后续行动和结算，保留逃离时状态。N−1人逃离即结束。
- 所有未逃离玩家在同一日全部跳过，立即提前周结。没有固定周数、总收入上限或核心牌张数门槛。

## 数据和验证

[完整牌表](docs/cards-v0.24.2.md) · [当前预算](docs/income-budget-v0.24.2.md) · [对局验证](docs/rebalance-v0.24.2.json)

唯一卡池来源为`data/cardpool-v24.2.json`。运行`npm run generate`，生成网页数据和牌表；不要直接改`src/cardpool-data.js`。旧v0.10运行导出器已阻止覆盖新版，历史分析脚本不用于生成本版。

`npm test`运行新版规则、UI、退役与构筑测试；`npm run check:cards`检查生成一致性；`node scripts/check-balance-v24.2.mjs`为独立静态预算。自动对局命令见设计说明。静态可行不等于随机市场平衡，自动对局不等于真人体验。

`src/engine.js`负责规则；`src/app.js`与卡面模块负责页面；`src/rules-v24.2.js`负责帮助文案。`tests/legacy-v21`保留旧规则测试快照，不计入当前通过数量。

`output/pdf/`仍为v0.6归档印刷品，不适用于当前规则。

本轮189项活跃测试通过，包括四条路线从空手开局取得真实技能、按有限供给购买并逃离的完整流程。测试控制的有利市场不等同于随机市场胜率。
