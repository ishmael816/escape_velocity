# 逃离工位 · 网页试玩版 0.6

实体桌游规则验证版：从周日的两格空闲开始，完成活动积累技能，寻找高级牌，构筑第二职业并逃离工位。支持 2–4 人同机轮流操作，或一名真人与自动玩家游玩。

## 启动与验证

需要 Node.js 24 或更新版本，无第三方依赖。

```powershell
cd E:\Projects\escape_velocity
npm run dev
```

浏览器打开 http://127.0.0.1:5173/ 。服务仅监听本机。

- `npm test`：48 项规则检查，包含 9 场完整自动对局。
- `npm run simulate`：输出 2–4 人、三个种子的周数、技能、收入与结算步数。
- `npm run simulate -- --matrix --output docs/simulation-v0.6.json`：四种起始恢复方式共 36 场对照。

## 第一局怎么操作

1. 默认是“你 + 两位自动玩家”。每周各采购两次；可以买公共市场、报名成长活动或购买个人双休项目，也可以躺平恢复 4 理智。起始已有周日看场演出、零散接单；设置中可改用手作、郊游、宅家作为恢复起点。
2. 点“路线图鉴”看 A 创作、B 技术、C 经营的成长路线。公共区仅按时长陈列：1h 四张、2h 三张、4h 两张，购买后立即从对应牌堆补位。时间机会、生活与副业混合陈列。支付 3 资金报名一个成长方向，从该牌堆抽二选一；交流活动可进一步抽选高级牌。
3. 采购结束，选手牌再点时段安排。最初只有周日白天自由；摸鱼打开工作时段的 1h 小槽，熬夜打开夜晚的 2h 中槽。点击时段可收回卡牌、移除机会或安排放空；也可试试自动安排，再手动调整。
4. 锁定后翻开公共事件，然后逐项、自动播放或一键结算。上班、默认休息不逐格执行，只结算实际安排。
5. 一次性成长活动成功后进入技能区；参加交流后在周末抽二选一。高级牌可以先拿到手中，满足技能后下周安排。技能不消耗。
6. 当周副业收入严格大于 24，可以逃离并永久获胜。N−1 人逃离的当周结束游戏；未逃离者总分达到 85 且理智至少 4 也获胜。

默认数值仍是试玩预设。第一周先扣工作维护与生活费，因此面板显示 18 资金、12 理智、4 灵感。早期恢复活动和躺平维持理智，之后用技能解锁更高效恢复、收入与永久核心。

## 本版内容

- 59 种牌按统一预算重新设计：基础重复净值 2/3/4，高级重复净值 4/6/8；资源结构、技能、寻访和核心另外定价。
- 12 种基础重复活动、18 种技能与交流活动、3 种一次性补给；购物只是恢复方式之一。
- 4 种起始恢复方式供对照试玩。演出为默认，手作、郊游、宅家仍属实验选项，并非等难度。
- 工具链和策划选题各只增强下一次成功副业；永久核心的折扣与加成均限定每周一次。

- 三条技能路线、18 种高级牌、6 种强效永久核心；图鉴公开技能组合和入门活动。
- 12 张共同事件：7 张抓包、2 张周日半天团建、1 张项目奖金、1 张双休通知、1 张平静。团建暂停在职玩家该时段活动，保留卡牌且不付执行消耗；已逃离者免疫。临时双休提前通知，下周可规划。
- 每周按工作日统一扣理智与生活费。摸鱼保留工资、没有额外工作扣除，但仍计入工作日；熬夜每周重复支付成本。
- 实体玩家板、内阴影凹槽、等宽且按 1∶2∶4 高度区分的牌体；技能归档托盘与永久能力区。
- 资源不足预警、缺少技能提示、规划撤销、自动排牌、完整日志、测试笔记与 JSON 导出。
- 本机自动存档，支持刷新续局。v0.6 使用独立存档键，不迁移或覆盖旧版存档；新游戏会替换当前版本存档。导出用于复盘，尚无导入界面。

## 文件结构

- `src/cards.js`：卡池、事件与测试参数。
- `src/engine.js`：独立规则引擎、确定性随机、预估与自动玩家。
- `src/app.js`：界面、操作、存档与导出。
- `src/style.css` / `src/tabletop.css` / `src/physical-board.css` / `src/progression.css`：页面、牌体、实体底板与技能区样式。
- `src/card-visuals.js`：颜色、时长与特殊规则展示。
- `tests/engine.test.mjs` / `scripts/simulate.mjs`：规则与完整对局验证。

自动对局用于检查流程与卡死问题，不能代替真人对策略乐趣、路线强度和 60–90 分钟目标时长的验证。
