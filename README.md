# 逃离工位 · 网页试玩版 0.9

实体桌游规则验证版：每人每周七次行动，逐日安排工作之外的生活与副业。支持 2–4 人同机轮流，或一名真人与自动玩家。

## 启动

需要 Node.js 24+，无第三方依赖。

```powershell
npm run dev
```

打开 http://127.0.0.1:5173/ 。仅监听本机。

## 第一局

1. 周初公开事件和查岗时段。每个周一至周日，玩家按座次各行动一次；全员行动后才进入下一天。每周起始玩家轮换。
2. 每次选一个：购买一张牌；安排、移动或撤回一张日程牌；整备拿 2 元，或刷新一张市场明牌。购买和安排分两次行动。
3. 点手牌的“安排”，再点绿色时段。只能操作今天及以后的日程。已安排的牌跨周保留；移动不能从已过去的日期取牌。
4. 上午、下午仍各 4h，2h/4h 各占一个白天槽；8h 卡跨同一天上午和下午，只在下午执行一次。夜晚最多两张 2h 或一张 4h，不能放 8h。理智为 0–10 状态条，起点 3，加自主状态（永久双休 2、逃离改为 4），上限 10，再减日程压力和当周问责。4h 夜晚额外压力 4。撤回只解除对应压力，没有理智恢复收益。技能积累仅用于解锁，不提高理智。
5. 市场只分 2h/4h/8h，展示 5/4/3 张，购买即补。高级牌都在 8h 堆，可以先买，凑齐技能后再安排。「争取双休」也是 8h 牌，成功执行三周后永久解放周六。
6. 周日行动完成后，只结算自定义日程，再结工资、生活费和事件奖励。支持逐时段或一键结算。生活牌仅供应灵感；成长完成移入技能区；研讨会和猎头从未亮出的 8h 高级牌抽二选一。
7. 当周副业收入严格大于 16 可以逃离。N−1 人逃离的当周立即结束；逃离者获胜，未逃离者为“究极牛马”。

抓包产生的当周问责在下周开始清零，资金罚款不返还。重复安排、撤回不能刷理智；没有卡牌直接增加或支付理智。

默认起始 16 资金、3 理智、4 灵感，持有宅家慢生活、零散接单、听完整张专辑，均需花行动安排。界面“新游戏 / 数值”可修改测试参数。整备不会恢复理智，默认休息也没有额外效果。

部分一次性活动需要多周完成：每周成功执行时支付一次推进消耗，放一个指示物；满格才获得完成效果并离开日程。暂停、移动和撤回保留进度；弃牌清除进度。「争取双休」需要三次，「出版合约」「自动化工作室」「自己的小店」需要两次。

## 规则与验证

- [本版规则与数值框架](docs/economy-v0.9.md)
- [测试结论与未解决问题](docs/playtest-v0.9.md)
- [全部 57 种卡牌](docs/cards-v0.9.md)
- `npm test`：46 项测试。删除成长理智加成后，43 项通过；2/3/4 人自动完整对局的终局检查失败（35 周测试上限内未结束），详见测试记录。
- `npm run simulate -- --matrix --output docs/simulation-v0.9.json`：36 场起始生活牌矩阵。
- `node scripts/audit-v9.mjs`：300 场自动对局。
- `node scripts/audit-basic-v9.mjs`：100 场无成长基础牌专项对局；加 `--growth` 再测允许一种成长及双休的 100 场。
- `node scripts/export-card-reference.mjs`：从实际卡牌数据重建数值表。

仓库中的 v0.9 对局 JSON 与截图是删除成长理智加成之前的历史数据，不能代表当前节奏。

自动对局用于发现流程卡死、非法资源和结算问题，不能证明路线平衡、真人体验或 60–90 分钟时长。v0.9 使用独立存档，不覆盖之前版本；刷新续局，JSON 可导出复盘，暂不支持导入。12 张事件含 8 张三时段查岗，确切时段周初公开；另外有奖金、临时双休、两张周日团建。

## A4 图纸版本

卡面图标新版：购买价在底栏，心智门槛与可逆压力在右上角，右下票券表示一次性（角标为完成所需次数），循环箭头表示多次活动。多周进度由圆孔指示物记录。图标使用内置 image_gen 生成的透明素材，原图与提示词保存在 `assets/card-ui/`；组装样张见 [卡面图片](assets/card-ui/card-layout-preview.jpg) 和 [预览页](designs/card-icon-layout.html)。实际渲染由 `src/card-face.js` 与 `src/card-face.css` 共享，规则和数值不变。

`output/pdf/` 和原打印脚本仍是 **v0.6 归档**，不适用于新版玩法。打印数据源已冻结在 `scripts/fixtures/print-cards-v0.6.json`，避免生成混合版本。本次更新网页规则与帮助，尚未重制 A4 玩家板和卡牌。

## 主要文件

- `src/cards.js`：最终卡牌定义、事件与默认参数。
- `src/engine.js`：日程行动、理智指标、结算、确定性随机与自动玩家。
- `src/app.js`、`src/icons.js`、`src/v7.css`、`src/v8.css`：界面、图标与玩家板样式；沿用实体底板，8h 卡跨两格。
- `tests/engine.test.mjs`、`scripts/simulate.mjs`：规则验证和对局报告。
