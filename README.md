# 逃离工位 · 网页试玩版 0.11

实体桌游规则验证版，支持 2–4 人同机轮流或自动玩家。四色卡池、隐藏查岗、活动骰与付费理智支持已接入；仍需真人测试卡池节奏与路线平衡。

## 启动与部署

需要 Node.js 24+，无第三方依赖。运行 `npm run dev`，打开 http://127.0.0.1:5173/ 。仅监听本机。

`npm run build` 生成 `dist/` 静态站点。Vercel 使用仓库内 `vercel.json`：Other 框架、构建命令 `npm run build`、输出 `dist`；生产分支以部署项目设置为准。本地修改不会自动部署。

## 第一局

1. 周初公开事件，查岗只预告次数。每天玩家轮流各行动一次，周一至周日共七次；每周轮换首位玩家。
2. 一次行动选购买一张牌、安排/移动/撤回一张牌，或整备。整备拿 1 钱，也可改为刷新一张明牌。购买与安排分开，只能调整今天及以后时段。
3. 2h、4h 各占一个白天槽；8h 跨上午与下午，下午执行一次。夜晚最多两张 2h 或一张 4h；4h 夜晚额外承担 4 压力。
4. 理智为 0–10 指标，起点 3；永久双休增加自主状态 2，逃离后自主状态改为 4，不叠加。加入有效支持牌贡献，再减日程压力。支持牌不逐周累加理智：查岗揭晓后、普通活动执行前支付本周维持费；费用不足、被查停、团建阻断或当晚安排满 4h 时失效。门槛在安排后与执行时检查，没有每周工作日扣理智。
5. 市场只有 2h/4h/8h 三堆，展示 5/4/3 张，购买即补。高级牌混在 8h 堆，可先购买，满足归档技能才可安排。职场 W、创作 A、开发 B、商业 C；同名归档不重复计技能。
6. 全员日程锁定后掷公共查岗骰：1–6 对应周一至周六，检查当天上午和下午；重复不重掷。每张被抓活动本周暂停、罚 1 钱，不按时长加罚，没有额外理智处罚，但被查停的支持牌失去本周贡献。8h 占两槽仍只罚一次。履职牌与休息时段不受查岗。
7. 按日程顺序执行活动，部分活动支付消耗后掷收益骰；结算固定工资 2 钱，无生活费。工资与奖金不计逃离，当周副业达到 10 且理智至少 6 可以逃离（先检查，再获得逃离自主状态），收入轨道最多 10。N−1 人逃离的当周结束；其余玩家为“究极牛马”。

默认开局 8 钱、3 理智、4 灵感，持有所选成长牌、跑腿代办、听完整张专辑，均需正常安排。已安排的常驻牌跨周保留。商业本金在安排时锁定，撤回返还；绿色增强只作用于紧接的一张活动，不跨周叠乘。

“争取双休”和“弹性工作授权”为个人项目，先满足职场信用，再购买启动与安排。双休需要三次成功推进，必须满足牌面条件；不是无条件领取。

`npm test`：60 项规则测试通过。`npm run build`：静态构建通过。本次 9 场自动对局中 5 场在 35 周内结束，4 场触发测试保护上限；尚不能认定多人节奏与卡牌平衡已通过验证。35 周仅为测试保护上限，游戏没有固定周数。

复现数据：依次运行 `node scripts/design-cardpool-v10.mjs`、`node scripts/export-runtime-v10.mjs`。复现静态检查：`node scripts/check-cardpool-v10.mjs`、`node scripts/check-dice-v10.mjs`。自动矩阵：`npm run simulate -- --matrix --output docs/simulation-v0.10.json`；任一局未结束时返回失败状态。

v0.11 使用独立存档，需要新开一局；旧版存档保留。刷新可续局，已掷骰结果保持；可导出 JSON 复盘，暂不支持导入。旧版对局记录不能代表当前规则。

## A4 与主要文件

`output/pdf/` 和打印脚本仍为 **v0.6 归档**，不适用于当前规则，本次未重制图纸。卡面沿用已有图标与角标素材，见 `assets/card-ui/`。

- `scripts/design-cardpool-v10.mjs`：卡池数据源；生成 `docs/cardpool-v0.10.json`，再导出 `src/cardpool-data.js`。
- `src/cards.js`：运行时适配、事件与默认参数。
- `src/engine.js`：行动、结算、骰子、自动玩家。
- `src/app.js`、`src/card-face.js`、`src/v10.css`：玩家板、卡面与骰子界面。
- `tests/`、`scripts/simulate.mjs`：规则与自动对局验证。
